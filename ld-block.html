Input File Format

Use a genotype VCF file and specify the genomic region to analyze. GWAS and GFF3 files are optional and can be used to add association and gene-annotation information to the LD visualization.

1. VCF / VCF.GZ — Required

Upload a standard VCF or VCF.GZ genotype file. The chromosome names in the VCF may use a genome-specific naming convention.

For example, the uploaded VCF may contain:

#CHROM                  POS      ID           REF  ALT  QUAL  FILTER  INFO  FORMAT  Sample1  Sample2
GLYMA.WM82.GNM4.GM01    24953    ss715578788  A    G    .     PASS    .     GT      1/1      0/0
GLYMA.WM82.GNM4.GM01    26004    ss715578818  C    T    .     PASS    .     GT      1/1      0/0
GLYMA.WM82.GNM4.GM01    29672    ss715578923  A    G    .     PASS    .     GT      0/0      1/1

Important: You do not need to enter the genome-specific chromosome name manually. Enter only the chromosome number in the Chromosome field. The website automatically detects the corresponding chromosome name from the uploaded VCF.

Example user input:

Chromosome: 18
Start position: 19901600
End position: 20231600

2. Genomic Region — Required

Enter the chromosome number and coordinate range separately. Chromosome numbers from 1–20 are supported.

Example:

Chromosome: 18
Start position: 19901600
End position: 20231600

Enter only the chromosome number. The website detects the corresponding chromosome name directly from the uploaded VCF, so you do not need to enter a genome-specific chromosome prefix.

3. GWAS P-value File — Optional

The GWAS file should contain three tab-separated columns: chromosome, genomic position, and P-value.

For example, a GWAS file may contain:

chr18    20050807    4.57837E-07
chr18    20053090    0.000569568
chr18    20056167    9.97487E-07
chr18    20059843    0.000420435

The chromosome name in the GWAS file does not need to match the VCF chromosome name exactly. Common formats such as 18, chr18, Chr18, or a genome-specific chromosome name can be used. The website automatically maps the GWAS chromosome to the corresponding chromosome in the uploaded VCF.

4. GFF3 Annotation — Optional

A standard GFF3 annotation file can be supplied to display gene annotation information for the selected genomic region. 

##gff-version 3
GLYMA.WM82.GNM4.GM18  source  gene  20050000  20060000  .  +  .  ID=gene1;Name=ExampleGene1

Analysis Parameters

  • LD measure: R², D′, or combined visualization.
  • MAF: minimum minor allele frequency filter.
  • Maximum missingness: maximum allowed missing genotype proportion.
  • GWAS cutline: optional threshold for displaying the GWAS significance line.
  • Show LD values: displays LD values in the visualization when available.

For large datasets, restrict the analysis to a focused genomic region rather than submitting an entire chromosome or genome.
