Method note: The browser implementation performs year/environment-effect adjustment followed by empirical shrinkage to generate BLUP-style genotype estimates. For balanced genotype × environment × replicate data, broad-sense entry-mean heritability is estimated as H² = σ²G / [σ²G + σ²G×E/E + σ²e/(E×R)]. These browser estimates are intended for exploratory phenotype analysis. For unbalanced designs, spatial effects, multiple random-effect structures, or formal REML inference, confirm the results using dedicated mixed-model software such as ASReml, sommer, lme4, or equivalent.
